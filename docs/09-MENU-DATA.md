# 09 – MENU DATA

# It's All Greek – Menu Source

Version: 1.0

Purpose:
Store the restaurant menu in one central location.

## Source of Truth

The menu must match the official restaurant menu exactly.

Primary source:
- Official It's All Greek website
- Official restaurant confirmation

If a discrepancy exists:
Ask before changing prices or descriptions.

## Data Structure

Each dish should contain:

- Category
- Name
- Description
- Price
- Optional image
- Optional popular flag

## Rules

- Never invent dishes.
- Never invent prices.
- Never rewrite descriptions.
- Preserve category order.
- Keep formatting consistent.

Status:
Menu data will be imported after verification from the official menu.
