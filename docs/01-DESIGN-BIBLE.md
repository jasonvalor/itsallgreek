# It's All Greek – Design Bible

Version: 1.0

This document is the single source of truth for the visual design of the It's All Greek website.

If this document and the approved design images conflict, the approved design images always take priority.

Never redesign.
Never improvise.
Never add visual elements that are not part of the approved designs.

---

# Design Philosophy

The website should feel:

- Modern
- Premium
- Warm
- Mediterranean
- Minimal
- Inviting
- Elegant
- Fast

The website should never feel:

- Cheap
- Busy
- Generic
- Overdecorated
- Cartoonish
- Template-like

---

# Mobile First

Always design mobile first.

Every page must look perfect on:

- Mobile
- Tablet
- Desktop

Desktop is an expansion of the mobile experience.

Never build desktop first.

---

# Visual Style

- Large, high-quality photography
- Plenty of breathing room
- Rounded corners
- Soft shadows
- Premium typography
- Simple navigation
- Minimal color palette
- High contrast
- Clean layouts
- Strong visual hierarchy

---

# Design Rules

- Never redesign an approved section.
- Never invent layouts.
- Never replace typography.
- Never introduce new colors.
- Never change spacing without a clear reason.
- Always follow the approved mockups.
- Keep visual consistency across every page.

---

# Layout

- Use generous vertical spacing between sections.
- Align all content to a consistent grid.
- Maintain consistent padding throughout the website.
- Whitespace is part of the design and should never feel wasted.

---

# Colors

Primary

- Blue

Secondary

- White

Accent

- Warm Mediterranean tones

Neutral

- Soft greys
- Dark charcoal for text where appropriate

Only use colors that appear in the approved designs.

---

# Typography

- Modern sans-serif
- Large headlines
- Bold hero titles
- Comfortable paragraph spacing
- Readable line lengths
- Consistent font hierarchy

---

# Buttons

Primary Button

- Filled
- Rounded
- Blue
- Bold text

Secondary Button

- Transparent
- Rounded
- Thin border
- Minimal styling

---

# Images

- Use large lifestyle photography.
- Avoid generic stock imagery.
- Images should feel authentic and premium.
- Photography should support the atmosphere, not distract from it.

---

# Icons

- Minimal
- Outlined
- Consistent stroke width
- Consistent sizing

---

# Shadows

- Very subtle
- Soft
- Never heavy or dramatic

---

# Border Radius

- Large rounded corners
- Consistent throughout the project
- Never sharp unless intentionally specified in the design

---

# Animations

Animations should be:

- Soft
- Short
- Purposeful
- Smooth

Animations should never:

- Distract
- Delay the user
- Feel gimmicky

---

# Responsiveness

- Mobile first
- No horizontal scrolling
- Touch-friendly controls
- Comfortable tap targets
- Consistent spacing across breakpoints

---

# Accessibility

- Proper color contrast
- Semantic HTML
- Keyboard accessible
- Alt text for every meaningful image
- Accessible forms and buttons

---

# Performance

- Lazy-load images where appropriate
- Optimize every asset
- Avoid unnecessary JavaScript
- Keep animations lightweight
- Prioritize fast loading times

---

# AI Development Rules

When implementing designs:

- Treat the approved design images as the primary source of truth.
- Do not redesign or reinterpret existing designs.
- Do not "improve" the visual design unless explicitly instructed.
- Reuse components whenever possible.
- Maintain consistency across all pages.

If something is unclear:

**When in doubt, ask instead of assume.**

Never guess.
Never invent missing details.
Always request clarification before making design decisions that are not explicitly documented.

---

# Final Rule

Build exactly what has been approved.

Consistency is more important than creativity.
