# Design Assets

## Purpose

This folder contains the approved visual designs for the It's All Greek website.

These files are the primary visual source of truth for the project.

If there is any difference between the documentation and the designs, the approved designs take precedence.

---

## Rules

- Never redesign an approved screen.
- Never change spacing, typography, colours or layout without approval.
- Never generate alternative designs unless explicitly requested.
- Always implement the approved design as accurately as possible.

If something is unclear:

Ask before assuming.

## AI Instructions

Before implementing any UI:

1. Review every approved design in this folder.
2. Compare the implementation against the design.
3. Report any inconsistencies before continuing.

The goal is implementation, not interpretation.
