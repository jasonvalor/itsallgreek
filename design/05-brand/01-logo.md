# Logo Specification

Version: 1.0

## Purpose
Defines the official logo specifications for the It's All Greek website.

## Official Logo
- Filename: logo.png
- Location: public/images/logo.png
- Status: Approved

## Brand Colors
### Primary Blue
- HEX: #0D73C8
- RGB: 13, 115, 200

### Primary Black
- HEX: #111111
- RGB: 17, 17, 17

### White
- HEX: #FFFFFF

## Typography
The logo artwork is fixed and must never be recreated.

Closest matching fonts for the supporting text:
- Bebas Neue (preferred)
- Oswald
- Anton (fallback)

The word 'GREEK' is custom artwork and must always be used as the original image.

## Rules
- Never recreate the logo.
- Never stretch, recolor, rotate or distort it.
- Always use the original asset.
- Use brand blue (#0D73C8) for primary UI accents.

## Accessibility
Recommended alt text:
"It's All Greek Food & Drinks logo"
